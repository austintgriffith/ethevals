The evals

Twenty per pillar, eighty total. Each one is keyed to a mistake seen in real agent output. quiz is a question with a written answer. goal is a build task judged on the files left behind. deterministic evals have a computed answer and a regex or exact grader. judge evals are graded by a blind LLM against written conditions. Ported evals link to their source task.

Sources

  • BuidlGuidl/ethskills-evals — goal and quiz tasks with a blind LLM judge, one per ethskills claim. Most of the building and security evals come from here.
  • clawdbotatg/eth-evals — 242 closed-book tasks, deterministic graders, computed calldata. Most of the concepts and transactions evals come from here.
  • ethskills.com — the skill library these evals grade against. Every eval names the claim it tests.
ETHEVALS is open source. Add an eval, submit a card, or argue with a rubric on GitHub. Built by BuidlGuidl.
